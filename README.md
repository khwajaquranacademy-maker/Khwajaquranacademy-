# Khwaja Quran Academy
1. Supabase: new project -> SQL Editor -> run schema.sql. Authentication -> Users -> Add user (your admin email + password).
2. Open index.html, fill SB_URL and SB_KEY (Project Settings -> API: URL and anon/publishable key).
3. Push this folder to GitHub, then Vercel -> Add New Project -> import repo -> Deploy. Add your domain under Settings -> Domains.
4. Admin panel: yourdomain.com/admins/safe
